# Images Folder

All static images for the customer site.

## Current Images:
- `logo.png` - Restaurant logo (used in navbar and hero)
- `bg.jpg` - Background image for the site
- `burger.jpg`, `cake.jpg`, `salad.jpg` - Sample food images

## Adding Food Images:
When adding menu item images, name them clearly:
- Example: `doro-wot.jpg`, `kitfo.jpg`, `tibs.jpg`

## Fallback Image:
Add `fallback-food.jpg` for items without images.
